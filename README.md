Welcome to **FYIMP-CS-WORKS**, the comprehensive code and resource repository for students pursuing the **Five-Year Integrated Masters Programme (FYIMP) Computational Science** at the **Department of Information Technology, Kannur University**.

This repository is designed to host **all practical lab programs, assignments, mini-projects, and worksheets** across all semesters and programming paradigms throughout the FYIMP CS curriculum.

---

## 📌 Repository Overview

- **Institution:** Kannur University
- **Department:** Department of Information Technology
- **Programme:** Four-Year Integrated Major Programme (FYIMP) in Computer Science
- **Scope:** Complete practical collection including C, C++, Java, Python, Data Structures, Web Technologies, DBMS, Shell Scripting, and more.

## 💻 Semester Modules & Worksheets

### 1. Semester 3 — C Programming Lab (`SEM3-C`)

The [`SEM3-C/`](SEM3-C) directory contains solutions for the Semester 3 C Programming practical lab course.

| # | Program | Description | Core Concepts |
|---|---|---|---|
| 1 | [`1.c`](SEM3-C/1.c) | Read an integer and print its square | Basic I/O & Variables |

| 3 | [`3.c`](SEM3-C/3.c) | Check whether a number is even or odd | Control Statements (`if-else`) |
| 4 | [`4.c`](SEM3-C/4.c) | Find the largest of two numbers | Decision Making |
| 5 | [`5.c`](SEM3-C/5.c) | Print multiplication table of a given number | `for` Loops |
| 6 | [`6.c`](SEM3-C/6.c) | Sum of first 10 natural numbers | Loop Statements |
| 7 | [`7.c`](SEM3-C/7.c) | Calculate factorial of a number | User-defined Functions |
| 8 | [`8.c`](SEM3-C/8.c) | Check if a given number is prime | Primality Logic |
| 9 | [`9.c`](SEM3-C/9.c) | Find the largest element in an array | 1D Arrays |
| 10 | [`10.c`](SEM3-C/10.c) | Reverse elements of an array | Array Manipulation |
| 11 | [`11.c`](SEM3-C/11.c) | Find string length without `strlen()` | String Traversal |
| 12 | [`12.c`](SEM3-C/12.c) | Count number of vowels in a string | Character Processing |
| 13 | [`13.c`](SEM3-C/13.c) | Check if a string is a palindrome | String Reversal |

| 15 | [`15.c`](SEM3-C/15.c) | Check if a number is an Armstrong number | Digit extraction |

| 18 | [`18.c`](SEM3-C/18.c) | GCD and LCM of two numbers | Euclidean Algorithm |
| 19 | [`19.c`](SEM3-C/19.c) | Matrix Multiplication | 2D Arrays / Nested loops |

## 🤝 Guidelines for Adding New Programs

1. Create a folder named according to the semester and subject (e.g., `SEM4-JAVA/`, `SEM4-PYTHON/`, `SEM5-DBMS/`).
2. Keep source code clean, formatted, and well-commented.
3. Update this `README.md` file to include an index table for the newly added module.
