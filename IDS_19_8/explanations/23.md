# Question 23: Bubble Sort

## Problem Statement
Implement bubble sort by writing a program.

---

## Complete Code (`23.cpp`)
```cpp
// 23. implement bubble sort by writing a program

#include <iostream>
using namespace std;

int main() {
    int n;

    cout << "Enter number of elements: ";
    cin >> n;

    int arr[n];
    cout << "Enter " << n << " elements:" << endl;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    // Bubble sort
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    cout << "\nSorted array (Bubble Sort):" << endl;
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

## Line-by-Line Explanation

- **Line 1:** Program objective comment.

- **Line 3-4:** Standard headers (`iostream`, `using namespace std;`).

- **Line 6:** `int main() {`  
  Main entry point.

- **Line 7:** `int n;`  
  Number of elements to sort.

- **Line 9-15:**  
  Prompts and inputs array size `n` and `n` numbers into `arr`.

- **Line 18:** `for (int i = 0; i < n - 1; i++) {`  
  Outer pass loop. Bubble sort takes up to $n - 1$ passes to sort $n$ elements.

- **Line 19:** `for (int j = 0; j < n - i - 1; j++) {`  
  Inner comparison loop. Compares adjacent elements up to $n - i - 1$ (since the largest elements "bubble up" to the end with each pass $i$).

- **Line 20-25:**  
  ```cpp
  if (arr[j] > arr[j + 1]) {
      int temp = arr[j];
      arr[j] = arr[j + 1];
      arr[j + 1] = temp;
  }
  ```  
  If the left element is larger than the right element, swaps them using a temporary variable `temp`.

- **Line 28-32:**  
  Prints the sorted array elements.

- **Line 34:** `return 0;`

## Example Walkthrough
- Input array: `[5, 1, 4, 2]` (`n = 4`)
- **Pass 1 ($i=0$):**
  - Compare 5 and 1: $5 > 1 \rightarrow$ swap $\rightarrow [1, 5, 4, 2]$
  - Compare 5 and 4: $5 > 4 \rightarrow$ swap $\rightarrow [1, 4, 5, 2]$
  - Compare 5 and 2: $5 > 2 \rightarrow$ swap $\rightarrow [1, 4, 2, 5]$ (5 is in place)
- **Pass 2 ($i=1$):**
  - Compare 1 and 4: no swap
  - Compare 4 and 2: $4 > 2 \rightarrow$ swap $\rightarrow [1, 2, 4, 5]$ (4 is in place)
- **Pass 3 ($i=2$):**
  - Compare 1 and 2: no swap $\rightarrow [1, 2, 4, 5]$
- Final Sorted: `1 2 4 5`
