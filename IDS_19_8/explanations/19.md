# Question 19: Factorial and Fibonacci Using Recursion

## Problem Statement
Write a program to find factorial and fibonacci using recursion.

---

## Complete Code (`19.cpp`)
```cpp
// 19. write a program to find factorial and fibonacci using recursion

#include <iostream>
using namespace std;

// Recursive function for factorial
int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

// Recursive function for nth Fibonacci term
int fibonacci(int n) {
    if (n <= 0) {
        return 0;
    }
    if (n == 1) {
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    int num, terms;

    cout << "Enter a number to find its factorial: ";
    cin >> num;
    cout << "Factorial of " << num << " is: " << factorial(num) << endl;

    cout << "\nEnter number of terms for Fibonacci series: ";
    cin >> terms;
    cout << "Fibonacci series up to " << terms << " terms:" << endl;
    for (int i = 0; i < terms; i++) {
        cout << fibonacci(i) << " ";
    }
    cout << endl;

    return 0;
}
```

---

## Line-by-Line Explanation

- **Line 1:** Title comment.

- **Line 3-4:** `#include <iostream>` and `using namespace std;`

- **Line 6-12:** `int factorial(int n)`  
  - Defines recursive function for computing factorial $n!$.
  - **Base Case (Line 8-10):** `if (n <= 1) return 1;`  
    $0! = 1$ and $1! = 1$. This stops the recursion.
  - **Recursive Case (Line 11):** `return n * factorial(n - 1);`  
    Calls itself with $(n - 1)$, multiplying $n \times (n-1)!$.

- **Line 14-23:** `int fibonacci(int n)`  
  - Defines recursive function for calculating the $n$-th Fibonacci term.
  - **Base Cases:**
    - `if (n <= 0) return 0;` (0th term is 0)
    - `if (n == 1) return 1;` (1st term is 1)
  - **Recursive Step:** `return fibonacci(n - 1) + fibonacci(n - 2);`  
    Each term is the sum of the preceding two terms.

- **Line 25:** `int main() {`  
  Execution entry point.

- **Line 26:** `int num, terms;`  
  Variables: `num` for factorial input, `terms` for Fibonacci count.

- **Line 28-30:**  
  Prompts user for `num`, calls `factorial(num)` and prints the result.

- **Line 32-34:**  
  Prompts for `terms` (how many Fibonacci numbers to print).

- **Line 35-37:**  
  ```cpp
  for (int i = 0; i < terms; i++) {
      cout << fibonacci(i) << " ";
  }
  ```  
  Iterates $i$ from 0 to $terms - 1$, printing each Fibonacci number separated by a space.

- **Line 40:** `return 0;`
