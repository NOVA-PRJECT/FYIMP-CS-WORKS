# Question 14: Multiply Two Matrices

## Problem Statement
Write a program to multiply two matrix.

---

## Complete Code (`14.cpp`)
```cpp
// 14. program to multiply two matrix

#include <iostream>
using namespace std;

int main() {
    int r1, c1, r2, c2;

    cout << "Enter rows and columns for first matrix: ";
    cin >> r1 >> c1;

    cout << "Enter rows and columns for second matrix: ";
    cin >> r2 >> c2;

    if (c1 != r2) {
        cout << "Matrix multiplication not possible! Columns of first must equal rows of second." << endl;
        return 0;
    }

    int a[r1][c1], b[r2][c2], product[r1][c2];

    cout << "\nEnter elements of first matrix:" << endl;
    for (int i = 0; i < r1; i++) {
        for (int j = 0; j < c1; j++) {
            cin >> a[i][j];
        }
    }

    cout << "\nEnter elements of second matrix:" << endl;
    for (int i = 0; i < r2; i++) {
        for (int j = 0; j < c2; j++) {
            cin >> b[i][j];
        }
    }

    // Initializing product matrix elements to 0
    for (int i = 0; i < r1; i++) {
        for (int j = 0; j < c2; j++) {
            product[i][j] = 0;
        }
    }

    // Matrix multiplication
    for (int i = 0; i < r1; i++) {
        for (int j = 0; j < c2; j++) {
            for (int k = 0; k < c1; k++) {
                product[i][j] += a[i][k] * b[k][j];
            }
        }
    }

    cout << "\nResultant Matrix after multiplication:" << endl;
    for (int i = 0; i < r1; i++) {
        for (int j = 0; j < c2; j++) {
            cout << product[i][j] << "\t";
        }
        cout << endl;
    }

    return 0;
}
```

## Line-by-Line Explanation

- **Line 1:** Program objective comment.

- **Line 3-4:** Includes `<iostream>` and specifies namespace `std`.

- **Line 6:** Entry point `main()`.

- **Line 7:** `int r1, c1, r2, c2;`  
  Stores rows and columns of matrix 1 and matrix 2.

- **Line 9-13:**  
  Takes input for dimensions of both matrices.

- **Line 15-18:**  
  ```cpp
  if (c1 != r2) {
      cout << "Matrix multiplication not possible! ...";
      return 0;
  }
  ```  
  **Rule of Matrix Multiplication:** Multiplication is defined only if the number of columns in the first matrix equals the number of rows in the second matrix ($c1 == r2$). If not, exit.

- **Line 20:** `int a[r1][c1], b[r2][c2], product[r1][c2];`  
  Declares matrix `a`, matrix `b`, and result matrix `product` which has dimensions $r1 \times c2$.

- **Line 22-35:**  
  Inputs elements for both matrices.

- **Line 37-42:**  
  ```cpp
  for (int i = 0; i < r1; i++) {
      for (int j = 0; j < c2; j++) {
          product[i][j] = 0;
      }
  }
  ```  
  Initializes every element in `product` to 0 so we can accumulate sums.

- **Line 44-52:**  
  ```cpp
  for (int i = 0; i < r1; i++) {
      for (int j = 0; j < c2; j++) {
          for (int k = 0; k < c1; k++) {
              product[i][j] += a[i][k] * b[k][j];
          }
      }
  }
  ```  
  **Core 3-Loop Multiplication Logic:**  
  - Loop `i`: Runs over rows of Matrix A (from `0` to `r1-1`).
  - Loop `j`: Runs over columns of Matrix B (from `0` to `c2-1`).
  - Loop `k`: Multiplies the $k$-th element of row $i$ of A with the $k$-th element of column $j$ of B, adding it into `product[i][j]`.

- **Line 54-60:**  
  Prints the resulting $r1 \times c2$ matrix.

- **Line 62:** `return 0;`  
  Ends execution.

## Example Walkthrough
- Matrix A ($2 \times 2$): $\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$
- Matrix B ($2 \times 2$): $\begin{pmatrix} 2 & 0 \\ 1 & 2 \end{pmatrix}$
- Cell [0][0] = $(1 \times 2) + (2 \times 1) = 2 + 2 = 4$
- Cell [0][1] = $(1 \times 0) + (2 \times 2) = 0 + 4 = 4$
- Cell [1][0] = $(3 \times 2) + (4 \times 1) = 6 + 4 = 10$
- Cell [1][1] = $(3 \times 0) + (4 \times 2) = 0 + 8 = 8$
- Product: $\begin{pmatrix} 4 & 4 \\ 10 & 8 \end{pmatrix}$
