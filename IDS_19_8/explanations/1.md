# Question 1: Find Minimum of 10 Numbers

## Problem Statement
Write a program to find the minimum of a set of 10 numbers.

---

## Complete Code (`1.cpp`)
```cpp
// 1. write a program to find the minimum of a set of 10 numbers

#include <iostream>
using namespace std;

int main() {
    int arr[10];

    cout << "Enter 10 numbers:" << endl;
    for (int i = 0; i < 10; i++) {
        cin >> arr[i];
    }

    int min = arr[0];
    for (int i = 1; i < 10; i++) {
        if (arr[i] < min) {
            min = arr[i];
        }
    }

    cout << "Minimum number is: " << min << endl;

    return 0;
}
```

---

## Line-by-Line Explanation

- **Line 3:** `#include <iostream>`

- **Line 4:** `using namespace std;`  
  Allows using standard names like `cout`, `cin`, and `endl` directly without writing `std::cout`.

- **Line 6:** `int main() {`  
  The entry point of every C++ program where execution begins. Returns an integer status code to the OS.

- **Line 7:** `int arr[10];`  
  Declares an integer array named `arr` with capacity for 10 elements (indexed from 0 to 9).

- **Line 9:** `cout << "Enter 10 numbers:" << endl;`  
  Prints a message on the screen prompting the user to enter 10 numbers. `endl` moves the cursor to a new line.

- **Line 10:** `for (int i = 0; i < 10; i++) {`  
  A loop starting with loop variable `i = 0`, running as long as `i < 10`, incrementing `i` by 1 in each step.

- **Line 11:** `cin >> arr[i];`  
  Reads a number from standard input (keyboard) and stores it at index `i` of the array `arr`.

- **Line 12:** `}`  
  Closes the input loop after 10 numbers are collected.

- **Line 14:** `int min = arr[0];`  
  Assumes the first element (`arr[0]`) is the minimum number and stores it in variable `min`.

- **Line 15:** `for (int i = 1; i < 10; i++) {`  
  Loops through the remaining 9 elements (from index 1 up to index 9).

- **Line 16:** `if (arr[i] < min) {`  
  Compares the current element `arr[i]` with the current smallest value `min`.

- **Line 17:** `min = arr[i];`  
  If the current element is smaller than `min`, update `min` to hold this new smaller value.

- **Line 18:** `}`  
  Ends the `if` condition block.

- **Line 19:** `}`  
  Ends the comparison `for` loop.

- **Line 21:** `cout << "Minimum number is: " << min << endl;`  
  Prints the final minimum value found.

- **Line 23:** `return 0;`  
  Returns exit status code 0 indicating successful execution of the program.

- **Line 24:** `}`  
  Closes the `main` function.

## Example Walkthrough

- Step-by-step comparisons:

  - 89 not < 12
