# Question 22: Binary Search

## Problem Statement
Write a program for implementing binary search.

---

## Complete Code (`22.cpp`)
```cpp
// 22. write a program for implementing binary search

#include <iostream>
using namespace std;

int main() {
    int n, key;

    cout << "Enter number of elements: ";
    cin >> n;

    int arr[n];
    cout << "Enter " << n << " elements in sorted (ascending) order:" << endl;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    cout << "Enter element to search: ";
    cin >> key;

    int low = 0;
    int high = n - 1;
    int foundIndex = -1;

    while (low <= high) {
        int mid = (low + high) / 2;

        if (arr[mid] == key) {
            foundIndex = mid;
            break;
        } else if (arr[mid] < key) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }

    if (foundIndex != -1) {
        cout << "Element " << key << " found at index " << foundIndex << " (Position " << foundIndex + 1 << ")." << endl;
    } else {
        cout << "Element " << key << " not found in the array." << endl;
    }

    return 0;
}
```

---

## Line-by-Line Explanation

- **Line 1:** Program comment.

- **Line 3-4:** `#include <iostream>` and `using namespace std;`

- **Line 6:** `int main() {`  
  Execution entry.

- **Line 7:** `int n, key;`  
  Array length and search value.

- **Line 9-15:**  
  Prompts user for size and takes $n$ elements in sorted order (binary search strictly requires sorted data).

- **Line 17-18:**  
  Takes search `key`.

- **Line 20-22:**  
  - `int low = 0;` points to the start of search interval.
  - `int high = n - 1;` points to the end of search interval.
  - `int foundIndex = -1;` holds result index.

- **Line 24:** `while (low <= high) {`  
  Repeats as long as search space has at least one candidate element.

- **Line 25:** `int mid = (low + high) / 2;`  
  Finds midpoint index of the current range.

- **Line 27-30:**  
  ```cpp
  if (arr[mid] == key) {
      foundIndex = mid;
      break;
  }
  ```  
  If the middle element matches `key`, search succeeds! Record index and exit loop.

- **Line 30-32:**  
  ```cpp
  else if (arr[mid] < key) {
      low = mid + 1;
  }
  ```  
  If `arr[mid]` is less than `key`, the key must lie in the right half, so update `low = mid + 1`.

- **Line 32-34:**  
  ```cpp
  else {
      high = mid - 1;
  }
  ```  
  Otherwise, `arr[mid]` is greater than `key`, so the key must lie in the left half; update `high = mid - 1`.

- **Line 37-41:**  
  Prints found location or not found message.

- **Line 43:** `return 0;`

## Example Walkthrough
- Array: `[10, 20, 30, 40, 50]` (`n = 5`), `key = 40`
  - Iteration 1: `low = 0, high = 4`, `mid = (0+4)/2 = 2`.  
    `arr[2] = 30 < 40` $\rightarrow$ `low = mid + 1 = 3`.
  - Iteration 2: `low = 3, high = 4`, `mid = (3+4)/2 = 3`.  
    `arr[3] = 40 == 40` $\rightarrow$ Found at index 3!
- Output: `Element 40 found at index 3 (Position 4).`
