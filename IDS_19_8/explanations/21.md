# Question 21: Linear Search

## Problem Statement
Write a program for implementing linear search.

---

## Complete Code (`21.cpp`)
```cpp
// 21. write a program for implementing linear search

#include <iostream>
using namespace std;

int main() {
    int n, key;

    cout << "Enter number of elements: ";
    cin >> n;

    int arr[n];
    cout << "Enter " << n << " elements:" << endl;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }

    cout << "Enter element to search: ";
    cin >> key;

    int foundIndex = -1;
    for (int i = 0; i < n; i++) {
        if (arr[i] == key) {
            foundIndex = i;
            break;
        }
    }

    if (foundIndex != -1) {
        cout << "Element " << key << " found at index " << foundIndex << " (Position " << foundIndex + 1 << ")." << endl;
    } else {
        cout << "Element " << key << " not found in the array." << endl;
    }

    return 0;
}
```

  **Linear Search Logic:**  
  Sequentially checks each element from index 0 to $n-1$. If `arr[i] == key`, saves index in `foundIndex` and breaks out immediately.

  - $i=1$: `8 == 42` (False)
