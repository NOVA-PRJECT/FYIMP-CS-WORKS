# Question 12: Add Two Matrices

## Problem Statement
Write a program to add two matrix.

---

## Complete Code (`12.cpp`)
```cpp
// 12. write a program to add two matrix

#include <iostream>
using namespace std;

int main() {
    int r, c;

    cout << "Enter number of rows: ";
    cin >> r;
    cout << "Enter number of columns: ";
    cin >> c;

    int a[r][c], b[r][c], sum[r][c];

    cout << "\nEnter elements of first matrix:" << endl;
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            cin >> a[i][j];
        }
    }

    cout << "\nEnter elements of second matrix:" << endl;
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            cin >> b[i][j];
        }
    }

    // Adding matrices
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            sum[i][j] = a[i][j] + b[i][j];
        }
    }

    cout << "\nSum of the two matrices:" << endl;
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            cout << sum[i][j] << "\t";
        }
        cout << endl;
    }

    return 0;
}
```

---

## Line-by-Line Explanation

- **Line 1:** `// 12. write a program to add two matrix`  
  Title comment.

- **Line 3-4:** Library header `#include <iostream>` and `using namespace std;`.

- **Line 6:** `int main() {`  
  Entry point of execution.

- **Line 7:** `int r, c;`  
  Stores the common row count `r` and column count `c` (two matrices can only be added if they have identical dimensions).

- **Line 9-12:**  
  Prompts and reads the matrix dimensions `r` and `c`.

- **Line 14:** `int a[r][c], b[r][c], sum[r][c];`  
  Declares three 2D arrays of size $r \times c$: matrix `a`, matrix `b`, and result matrix `sum`.

- **Line 16-22:**  
  Reads $r \times c$ integers into first matrix `a`.

- **Line 24-30:**  
  Reads $r \times c$ integers into second matrix `b`.

- **Line 32-37:**  
  ```cpp
  for (int i = 0; i < r; i++) {
      for (int j = 0; j < c; j++) {
          sum[i][j] = a[i][j] + b[i][j];
      }
  }
  ```  
  Performs element-wise addition: each cell in `sum[i][j]` is calculated as $a[i][j] + b[i][j]$.

- **Line 39-45:**  
  ```cpp

      for (int j = 0; j < c; j++) {
          cout << sum[i][j] << "\t";
      }
      cout << endl;
  }
  ```  
  Displays the result in grid form. `\t` inserts a tab between column elements, and `cout << endl;` starts a new line after each row.

- **Line 47:** `return 0;`  
  Normal termination.

## Example Walkthrough

  $\begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$

  $\begin{pmatrix} 5 & 6 \\ 7 & 8 \end{pmatrix}$
