# Question 11: Create Matrix and Print Elements with Memory Addresses

## Problem Statement
Write a program to create a matrix with m×n size with integer values and print all elements in the matrix and corresponding address.

---

## Complete Code (`11.cpp`)
```cpp
// 11. write a program to create a matrix with m*n size with integer values and print all elements in the matrix and corresponding address

#include <iostream>
using namespace std;

int main() {
    int m, n;

    cout << "Enter number of rows (m): ";
    cin >> m;
    cout << "Enter number of columns (n): ";
    cin >> n;

    int matrix[m][n];

    cout << "Enter elements of the matrix (" << m << "x" << n << "):" << endl;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cin >> matrix[i][j];
        }
    }

    cout << "\nMatrix elements and their memory addresses:" << endl;
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cout << "Element [" << i << "][" << j << "] = " << matrix[i][j] 
                 << "  |  Address = " << &matrix[i][j] << endl;
        }
    }

    return 0;
}
```

## Line-by-Line Explanation

- **Line 1:** `// 11. write a program to create a matrix with m*n size with integer values and print all elements in the matrix and corresponding address`  
  Title comment.

- **Line 3-4:** Standard headers (`iostream`, namespace `std`).

- **Line 6:** `int main() {`  
  Entry point of execution.

- **Line 7:** `int m, n;`  
  `m` represents rows; `n` represents columns.

- **Line 9-12:**  
  Prompts and reads the dimensions `m` and `n`.

- **Line 14:** `int matrix[m][n];`  
  Declares a 2D integer array (matrix) of dimensions $m \times n$.

- **Line 16-21:**  
  ```cpp
  for (int i = 0; i < m; i++) {
      for (int j = 0; j < n; j++) {
          cin >> matrix[i][j];
      }
  }
  ```  
  Nested loops: outer loop iterates through row index `i` (from 0 to $m-1$), inner loop iterates through column index `j` (from 0 to $n-1$), reading each matrix cell.

- **Line 24-29:**  
  ```cpp
  for (int i = 0; i < m; i++) {
      for (int j = 0; j < n; j++) {
          cout << "Element [" << i << "][" << j << "] = " << matrix[i][j] 
               << "  |  Address = " << &matrix[i][j] << endl;
      }
  }
  ```  
  - `matrix[i][j]`: Evaluates to the integer value stored at row `i`, column `j`.
  - `&matrix[i][j]`: The `&` (address-of) operator retrieves the hexadecimal memory address where that cell is stored in RAM.
  - Notice that addresses increase by 4 bytes (size of an `int` in C++) continuously, demonstrating row-major storage.

- **Line 31:** `return 0;`  
  Clean exit.
